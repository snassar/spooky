# Focused ADR Analyzer Tool

## Purpose
Performs focused analysis of ADRs (Architecture Decision Records) to identify specific patterns and insights.

## Usage
```bash
# Build the tool
just build

# Perform focused ADR analysis
just run
```

## Output
Provides focused analysis of ADRs with specific insights and recommendations.

## Configuration
This tool performs targeted analysis of ADRs to extract specific insights and patterns.

- Go 1.24+
