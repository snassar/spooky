# Simple ADR Generator Tool

## Purpose
Generates simple ADR (Architecture Decision Record) documentation with minimal complexity.

## Usage
```bash
# Build the tool
just build

# Generate simple ADR documentation
just run
```

## Output
Generates simplified ADR documentation in the `docs/adr/` directory.

## Configuration
This tool creates basic ADR documentation with minimal formatting and complexity.

## Dependencies
- Go 1.24+
- Access to the spooky codebase
