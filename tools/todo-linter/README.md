# TODO Linter Tool

## Purpose
Lints TODO comments in the codebase to ensure they follow project standards and conventions.

## Usage
```bash
# Build the tool
just build

# Lint TODO comments
just run
```

## Output
Analyzes TODO comments and reports any issues with formatting, content, or project standards.

## Configuration
This tool scans the codebase for TODO comments and validates them against project conventions.

## Dependencies
- Go 1.24+
- Access to the spooky codebase
